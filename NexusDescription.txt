[center][size=4]When a hero is [color=#93c47d]taken prisoner[/color], their captor [color=#93c47d]strips their equipment[/color] and leaves them in [color=#93c47d]tattered rags[/color].[/size]
[size=4]Captor [color=#93c47d]traits and relations[/color] decide who gets robbed and who is spared.[/size]
[i](In honor of [url=https://www.nexusmods.com/profile/Cheyron/mods]Cheyron[/url] mods)[/i]

[color=#93c47d][size=3]Supported game versions: 1.5.7, 1.4.8, 1.4.7.[/size][/color]

[img]https://i.ibb.co/FkbLZ6NL/Shackles.png[/img][/center]

[color=#ffff00][size=4]Features[/size][/color]
[color=#ffd966]Captured heroes always lose their weapons, banner, horse and harness. If the armor roll passes, armor is taken in order: helmet, gloves, cape, then body armor together with boots. The first failed roll stops the stripping. Everything taken goes to the captor's inventory.[/color]
[color=#93c47d]Stripped heroes are dressed in tattered rags. Heroes released while still in rags receive a fresh vanilla-generated equipment set.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#ffd966]Minimum item value filter - cheap armor is never taken.[/color]
[color=#93c47d]Choose which equipment sets can be taken: Battle, Civilian, Stealth.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color] each)
[color=#ffd966]Choose who can lose gear: AI heroes, the player, player clan members, player caravan masters.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color] each)
[color=#93c47d]When you capture a hero, their gear is added to your inventory.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#ffd966]Bandits always take armor, ignoring the armor loss chance roll.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#93c47d]Honorable or Merciful captor leaders never take armor (weapons and horse are still taken). Dishonorable leaders always do.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color] each)
[color=#ffd966]Friendly captors spare armor when their relation with the prisoner is at or above an adjustable threshold.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#93c47d]When a hero is executed, all their equipment goes to the executioner's party inventory. Works for player and AI executions.[/color] ([color=#6aa84f]on[/color]/[color=#e06666]off[/color])
[color=#ffd966]Works with or without Mod Configuration Menu.[/color]
[color=#93c47d]Translations for 12 languages.[/color]

[color=#ffff00][size=4]Settings[/size][/color]
[color=#6fa8dc]General[/color]
[color=#ffd966]Armor Loss Chance[/color] - 0% to 100%, default [color=#93c47d]80%[/color] (rolled once per capture; weapons and horse are always taken)
[color=#ffd966]Next Armor Piece Chance[/color] - 0% to 100%, default [color=#93c47d]80%[/color] (rolled for each armor step; 100% strips everything)
[color=#ffd966]Minimum Item Value[/color] - 0 to 100000 denars, default [color=#93c47d]200[/color] (armor only; 0 = no filter)
[color=#ffd966]Re-equip On Release[/color] - default [color=#6aa84f]on[/color]
[color=#6fa8dc]Equipment Sets[/color]
[color=#ffd966]Battle Gear[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Civilian Gear[/color] - default [color=#e06666]off[/color]
[color=#ffd966]Stealth Gear[/color] - default [color=#e06666]off[/color]
[color=#6fa8dc]Who Loses Gear[/color]
[color=#ffd966]AI Heroes[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Player[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Player Clan Members[/color] - default [color=#6aa84f]on[/color] (caravan masters not included)
[color=#ffd966]Player Caravan Masters[/color] - default [color=#6aa84f]on[/color]
[color=#6fa8dc]Captor Rules[/color]
[color=#ffd966]Player Takes Gear As Captor[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Bandits Always Take Armor[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Honorable Captors Spare Armor[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Merciful Captors Spare Armor[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Dishonorable Captors Always Take Armor[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Friendly Captors Spare Armor[/color] - default [color=#6aa84f]on[/color]
[color=#ffd966]Friendly Relation Threshold[/color] - -100 to 100, default [color=#93c47d]10[/color]
[color=#ffd966]Take All Equipment After Execution[/color] - default [color=#6aa84f]on[/color]
[color=#6fa8dc]Technical settings[/color]
[color=#ffd966]Logging for debugging[/color] - default [color=#e06666]off[/color]

[color=#6fa8dc]With Mod Configuration Menu:[/color] change them in game under [color=#ffd966]Options > Mod Options[/color]. Changes apply at once.
[color=#6fa8dc]Without Mod Configuration Menu:[/color] open [color=#ffd966]Modules[/color]\[color=#f1c232]GearLossOnCapture[/color]\[color=#ffd966]ModConfiguration.xml[/color] in any text editor. The file is read every time a campaign is started or loaded. If it is deleted or broken, the mod creates a new one with the default values.

[color=#ffff00][size=4]Game versions[/size][/color]
[color=#93c47d]1.5.7[/color], [color=#93c47d]1.4.8[/color], [color=#93c47d]1.4.7[/color] in the same download. The mod picks the right files for your game by itself.

[color=#ffff00][size=4]Compatibility[/size][/color]
Can be added/removed [color=#93c47d]anytime[/color].
Does [color=#93c47d]not add data[/color] to save game files.
[color=#93c47d]No Harmony patches[/color], uses only campaign events.

[color=#ffff00][size=4]Requirements[/size][/color]
[url=https://www.nexusmods.com/mountandblade2bannerlord/mods/612]Mod Configuration Menu[/url] - [color=#6aa84f]optional[/color], for changing the settings in game.

[color=#ffff00][size=4]Installation[/size][/color]
Updating? [color=#e06666]Delete the old mod folder first[/color], never overwrite it.
Advisable to use [color=#ffd966]7zip[/color] to extract archive.
Put it in [color=#ffd966]Mount & Blade II Bannerlord[/color]\[color=#f1c232]Modules[/color] folder.
Enable the mod in the launcher. [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/612]Mod Configuration Menu[/url] (if you use it) must be above it.

[color=#ffff00][size=4]Found a problem?[/size][/color]
Generate a crash report link using [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2018]ButterLib[/url] mod. How to do that the mini guide is here: [url=http://bannerlordmodding.lt/guides/how_to_report_a_crash/]How To Report A Crash[/url]
Turn on [color=#ffd966]Logging for debugging[/color] in [color=#ffd966]MCM[/color] settings or [color=#ffd966]ModConfiguration.xml[/color] in mod folder, [color=#f6b26b]repeat the problem[/color], then attach the file from [color=#ffd966]Modules[/color]\[color=#f1c232]GearLossOnCapture[/color]\[color=#ffd966]logs[/color] to your [url=https://www.nexusmods.com/mountandblade2bannerlord/mods/2018]ButterLib[/url] crash report.
